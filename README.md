# Restaurant Billing System

A Java-based console application developed during my 3rd semester to simulate a restaurant ordering and billing process. The system enables users to browse a menu, place orders, calculate bills automatically, and generate an itemized receipt.

## Features

* Interactive menu-driven interface
* Selection of multiple food items with custom quantities
* Automatic calculation of subtotal, tax, and final bill
* Support for multiple orders within a single transaction
* Generation of an itemized billing summary

## Object-Oriented Design

* **Encapsulation** through private data members and public getter methods
* **Abstraction** by separating billing and ordering logic into dedicated classes
* **Method Overriding** using the `toString()` method for customized menu display

## Concepts and Technologies

* Java
* Object-Oriented Programming (OOP)
* ArrayList Collections Framework
* User Input Handling using Scanner
* Basic Billing and Tax Computation
